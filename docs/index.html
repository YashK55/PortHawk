PortHawk

See every port your machine is listening on, and kill the stray dev server that shouldn't still be running.

Why

Every open localhost port on your machine is a running process, and it's easy to lose track of which ones still matter. A coding agent starts a dev server to test something, you move on, and the process just keeps listening in the background. PortHawk is a small, open-source process manager for exactly that situation: it reads your machine's open ports the same way netstat would, tells you what's actually behind each one, and lets you kill a stale server without hunting for its PID by hand.

Most existing port-monitor tools are closed-source, which means trusting an opaque extension with process and filesystem access. PortHawk doesn't ask for that trust — there's no telemetry, and the entire codebase is small enough to read in one sitting.

What it does

Run porthawk list or open the sidebar in your editor and you'll see every listening port, the process name behind it, and whether that process looks like it was spawned by a coding agent's terminal, started manually, or is unrecognized. porthawk watch gives you a live, arrow-key-driven view of the same thing in your terminal — press k and confirm to kill a port, no manual PID lookups required.

  • Cross-platform detection on Windows, macOS, and Linux
  • Tags each server as agent-spawned, manual, or unknown
  • Confirmation required before any kill, in both the CLI and the editor
  • No telemetry, ever, by default
  • Works in any Open VSX–based editor, not just VS Code
